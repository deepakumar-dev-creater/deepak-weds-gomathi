# Deepak Kumar & Gomathi — Wedding Invitation

A digital wedding invitation website for **Deepak Kumar & Gomathi**.

## Events & Celebrations
- **Wedding Reception**: 11th March 2027 at 7:00 PM
- **Wedding Ceremony (Muhurtham)**: 12th March 2027 at 9:00 AM
- **Venue**: En Sesha Mahal, Royapettah, Chennai
- **Location**: [Google Maps Location](https://share.google/9cDnaaYRR4evNU4Ec)

## Features
- **Live Countdown Timer**: Real-time ticker counting down to the wedding muhurtham.
- **Audio Experience**: Traditional wedding Shehnai background music with interactive toggle.
- **The Celebrations Carousel**: Interactive event slides featuring customized couple portraits (Royal Blue Reception & Traditional South Indian Muhurtham).
- **Responsive Layout**: Designed for mobile browsers and social sharing (WhatsApp/Facebook OpenGraph preview).

## Project Structure
- `index.html`: Full-screen responsive live preview container.
- `invite.html`: Wedding invitation application and artwork scene.
- `site.css`: Stylesheet with countdown and glassmorphism styling.
- `site.js`: Animation, audio player, and countdown timer logic.
- `assets/`: Media assets (music, images, dress code).
